# MoveNest PRD

## 产品目标

MoveNest 是一款面向欧美城市女性的轻量居家训练 App。它的目标不是让用户立刻进入高强度健身计划，而是在第一次打开产品时，帮助她们用低压力、低门槛的方式完成一节 10-15 分钟训练。Demo 的核心目标是证明：用户可以在 1 分钟内理解产品气质、看到今日推荐、判断课程是否适合自己，并顺利完成第一节训练。

## 目标用户

目标用户是 25-35 岁欧洲城市女性。她们工作节奏快，可能长期久坐，没有稳定健身习惯，也不一定愿意去健身房。她们对运动的期待更接近“让身体舒服一点、恢复能量、建立习惯”，而不是追求强烈消耗或身材焦虑。她们需要产品尊重个人状态，例如疲惫、膝盖不适、时间不足或居住空间有限。

## 核心链路

核心链路为 Welcome -> Home -> Workout Detail -> Active Workout -> Completion。Welcome 建立柔和可信的品牌第一印象；Home 给出一个今日推荐，并允许用户用三个状态选项快速调整；Detail 解释为什么这节课安全、低冲击、适合新手；Active Workout 模拟训练中体验，并允许用户反馈 Too hard；Completion 提供完成感和轻量反馈，为明日计划形成闭环。

## 核心功能

功能上聚焦四件事：第一，游客进入，降低注册阻力；第二，今日推荐，减少用户选择成本；第三，课程详情，用时长、强度、目标和动作预览降低不确定性；第四，训练中和训练后的反馈，让产品呈现 AI 个性化调整的逻辑。Demo 不接入真实 AI，而是用前端状态和文案表达个性化推荐、训练难度调整和次日计划保存。

## 关键指标

关键指标包括首次进入到点击 Start Workout 的转化率、用户是否在 1 分钟内找到课程、训练完成率、Too hard 等训练中反馈触发率、完成页反馈选择率，以及 Save tomorrow's 10-min plan 的点击率。这些指标能判断产品是否真正降低了开始训练的心理成本。

## Demo 范围选择

本 Demo 选择第一节训练的闭环，而不是完整课程库、社区或会员体系，因为笔试题关注核心流程和产品判断。对新用户来说，最关键的不是功能丰富，而是“现在就能开始，并且不会被吓退”。因此 Demo 保留最能体现产品价值的路径：快速推荐、低冲击说明、训练中调整、完成后反馈。
